# 🧠 AI Models

### 🛠️ Algorithm & Architecture (알고리즘 및 아키텍처)
* **Rule-based** (규칙 기반 접근)
* **Connectionist** (연결주의)
  * CNN / RNN
  * Transformer (Dense / MoE)
  * SSM (Mamba 등) / GNN (그래프 신경망)
* **Generative Models** (생성 모델)
  * Diffusion / Flow Matching
  * GAN / VAE
  * Autoregressive (AR) Models
* **Reinforcement & Agentic** (강화학습 및 에이전트)
  * RLHF / RLAIF (인간/AI 피드백 기반 강화학습)
  * Reasoning Frameworks (CoT, ToT, ReAct)
  * Autonomous Agents (Multi-agent 시스템)

### 🎯 Modality 
* **Language** 
  * LLM / sLM
* **Vision** 
  * Image / Video (생성, 인식, 편집)
  * 3D / Spatial (NeRF, 3D Gaussian Splatting, CAD)
* **Audio**
  * Speech (STT / TTS)
* **Multimodal**
  * LMM (Large Multimodal Models - Any-to-Any)
